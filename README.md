# Gmail Customizer

Gmail の利便性を向上させる Google Chrome 拡張機能です。検索時のタブタイトルの改善、日時の曜日表示、ワンクリックでのメール全文コピーを提供します。

## 主な機能

- **検索時タブタイトルの変更**: 検索実行時にタブタイトルへ検索キーワードを反映し、複数タブを開いている際でも目的の検索画面を素早く識別可能にします
- **日時の曜日表示**: メール一覧やメール詳細画面の日時表示に曜日を付加します (土日の色分けや当日メールへの曜日付加も設定可能)
- **メール全文コピーボタン**: 開いたメールの各メッセージヘッダーおよび上部ツールバーにコピーアイコンボタンを設置し、ワンクリックでメール本文をクリップボードにコピーできます
- **設定ポップアップ**: ツールバーの拡張機能アイコンから各機能の有効・無効や表示形式を柔軟にカスタマイズできます

    ├── content/

## インストール手順

1. Google Chrome を起動し、アドレスバーに `chrome://extensions/` と入力して Enter キーを押します
2. 画面右上にある「デベロッパーモード」のトグルスイッチをオンにします
3. 画面左上に表示される「パッケージ化されていない拡張機能を読み込む」ボタンをクリックします
4. 本リポジトリの `gmail-customizer` フォルダを選択します
5. 拡張機能一覧に「Gmail Customizer」が表示され、有効になっていればインストール完了です

## 設定項目

ブラウザの拡張機能バーにある Gmail Customizer アイコンをクリックすると、以下の設定を変更できます。

| 設定項目                     | 説明                                                 | 初期値                       |
| :--------------------------- | :--------------------------------------------------- | :--------------------------- |
| **検索時タブタイトル変更**   | 検索画面表示時にタブタイトルをカスタマイズ           | 有効 (`🔍 [検索語] - Gmail`) |
| **日時に曜日を追加**         | メール一覧および詳細の日時に `(水)` などの曜日を付加 | 有効                         |
| **土日を青/赤で色分け**      | 土曜日は青色、日曜日は赤色で曜日を表示               | 有効                         |
| **当日の時刻にも曜日を付加** | 時刻のみ表示される当日のメールにも曜日を付加         | 有効                         |
| **本文コピーボタン設置**     | メール詳細に全文コピーボタンを配置                   | 有効                         |
| **ヘッダーも含めてコピー**   | 本文コピー時に件名・差出人・日時も含める             | 無効 (本文のみ)              |
